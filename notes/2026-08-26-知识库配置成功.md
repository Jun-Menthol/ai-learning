# 2026-08-26 知识库（RAG）配置全过程

> 学习目标：让 Agent 能基于我上传的专属文档回答问题

## 一、什么是知识库（RAG）？

知识库让 Agent 能“阅读”我提供的专属资料，并基于这些资料回答问题。这就像给 Agent 配备了一本只属于我的参考书。

**核心价值**：让 Agent 能回答“它不知道，但我希望它知道”的问题。

## 二、操作步骤

### 第1步：准备资料文件

- 新建一个文本文件（.txt 或 .md）
- 将学习资料内容粘贴进去
- 保存为 `RAG科普文章.txt` 或其他名称

### 第2步：在 Coze 中找到知识库入口

在 Bot 编辑界面 → 左侧「知识」区域 → 点击「文本」

### 第3步：创建知识库

- 点击「创建扣子知识库」
- 填写名称：`my-ai-notes`
- 填写描述：`用于存储和检索AI学习笔记与科普文章`

### 第4步：配置知识库参数

| 配置项 | 选择 |
| :--- | :--- |
| 解析方式 | 「快速解析」（纯文本文件无需精准解析） |
| 分段策略 | 「自动分段与清洗」（对新手最友好） |
| 配置存储 | 「平台共享存储」（无需额外配置） |

### 第5步：上传文档

- 选择「本地文档」作为导入类型
- 点击上传，选择电脑中的 `RAG科普文章.txt` 文件
- 等待系统处理完成，显示“已就绪”

### 第6步：关联到智能体

- 点击「添加到智能体」
- 确认关联到当前的「AI学习助手」Bot

## 三、测试验证

**测试问题**：`根据你学过的资料，RAG的三个工作步骤是什么？`

**Agent 回答**：
1. 检索：当用户提出问题时，系统先到指定的知识库搜索与问题最相关的内容片段
2. 增强：系统把检索到的相关内容和用户的原问题组合，形成更完整的提示词
3. 生成：大语言模型根据增强后的提示词生成准确可靠的回答

**结论**：✅ 知识库成功生效，Agent 的回答基于上传的文档内容

## 四、我的理解

### RAG 的三个核心步骤

| 步骤 | 作用 | 通俗理解 |
| :--- | :--- | :--- |
| 检索 | 在知识库中找相关内容 | 先翻书找答案在哪 |
| 增强 | 把找到的内容和问题组合 | 把找到的答案和问题放到一起 |
| 生成 | 基于组合后的信息生成回答 | 看答案后组织语言回复 |

### 知识库 vs 联网搜索

| 能力 | 知识库 | 联网搜索 |
| :--- | :--- | :--- |
| 信息源 | 我上传的专属文档 | 全网公开信息 |
| 适用场景 | 学习笔记、公司内部制度、私有资料 | 天气、新闻、实时事件 |
| 核心价值 | 让 Agent 知道“只有我知道的事” | 让 Agent 知道“正在发生的事” |

## 七、心得体会

1. 知识库的配置选项虽然多，但新手只需要关注「解析方式」和「分段策略」，保持默认就能获得不错的效果
2. 上传的文档需要“可搜索”，结构化越好的文档（有标题、分章节），检索效果通常越好
3. 知识库和联网搜索是互补的，一个负责私有知识，一个负责实时信息
