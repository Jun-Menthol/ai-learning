# Agent 基础概念

> 学习日期：2026-08-25
> 来源：课堂学习 / 自学

## 什么是 Agent？

Agent（智能体）是一个能够**自主感知环境、做出决策并执行动作**的智能系统。

我的理解：Agent 就像一个"能自己动手干活"的 AI 助手，它不只会回答问题，还能调用工具、查资料、执行任务。

## Agent 的核心构成

| 组成部分 | 作用 | 我的理解 |
| :--- | :--- | :--- |
| **大模型（LLM）** | 理解语言、推理决策 | 相当于 Agent 的"大脑" |
| **工具调用（Tool Calling）** | 调用外部 API、数据库 | 相当于 Agent 的"手脚" |
| **记忆（Memory）** | 存储历史对话和上下文 | 相当于 Agent 的"记忆" |
| **规划（Planning）** | 分解复杂任务成步骤 | 相当于 Agent 的"思维" |

## Agent 的工作流程

1. 用户输入问题
2. Agent 用 LLM 理解意图
3. 如果需要，调用工具获取信息
4. 结合记忆和工具结果，生成回答
5. 返回给用户
