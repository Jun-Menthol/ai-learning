## 🧪 实验过程

### 遇到的问题
1. **第一次尝试**：使用「谷歌搜索」插件，提示 `API_KEY不能为空`<img width="1968" height="1075" alt="image" src="https://github.com/user-attachments/assets/0aca467f-c97f-4872-8b82-fb4a3cdf606e" />

2. **第二次尝试**：使用「必应谷歌搜索」插件，仍然需要 `apikey` 和 `authkey`<img width="2559" height="1398" alt="image" src="https://github.com/user-attachments/assets/9381722d-0497-4308-9ae5-e7ea7302f569" />

3. **根本原因**：部分搜索插件需要用户自行配置 API 密钥，不适合新手

### 解决方案
- 换用 Coze 官方出品的 **「头条搜索」** 插件
- 该插件为「官方免费网页搜索」，**无需额外配置**，添加即用

- 回复风格符合预设的「讲师」人设

## 💡 我的理解：什么是「工具调用」？

| 概念 | 我的理解 |
| :--- | :--- |
| **工具调用** | Agent 在需要时主动调用外部功能（如搜索、计算、查数据库）来获取信息或执行动作 |
| **为什么需要** | 大模型的知识截止到训练数据，无法获取实时信息（如天气、新闻） |
| **类比** | 就像人类遇到不会的问题时会去查资料、问别人，Agent 也会“找外援” |

## 🎓 今日心得体会

1. **插件选型很重要**：新手应优先选择「官方出品」且标注「免费」的插件，避免踩 API 密钥的坑
2. **工具调用是 Agent 的核心能力**：让 Agent 从“聊天”升级到“做事”的关键一步
3. **错误信息是老师**：`API_KEY不能为空` 这个报错引导我找到了正确的解决方案
